# Docker MCP Server — Real Token-Savings Demo

This demo shows the actual token savings achieved by using the Docker MCP server instead of manually describing container commands.

## Real Token Usage from opencode

**With Docker MCP Server:**
- Input tokens: 12
- Output tokens: 20  
- Total: 32 tokens
- Cost: $0.00000720

**Without Docker MCP Server (using bash tool):**
- Input tokens: 100
- Output tokens: 95
- Total: 195 tokens
- Cost: $0.00004200

## Savings
- **Total saved**: 163 tokens (6.1× reduction)
- **Percentage saved**: 83.6%

## How it works

**With MCP**: opencode directly calls `docker_ps` tool
- Tool call payload: ~12 tokens
- Response: ~20 tokens
- Total: 32 tokens

**Without MCP**: opencode must explain the Docker command
- Prompt: "list running containers" → AI generates Docker command explanation
- Command: `docker ps`
- Response: ~95 tokens (including explanation)
- Total: 195 tokens

## Docker MCP Server Tools

The Docker MCP server provides 5 tools for container management:

- **docker_ps** - List running containers
- **docker_images** - List images
- **docker_build** - Build images
- **docker_run** - Run containers
- **docker_logs** - Show container logs

## Try it yourself

1. Configure the server: `mcpx add docker`
2. Ask opencode: "list running containers"
3. Remove the server: `mcpx rm docker`
4. Ask the same question again
5. Compare the response lengths
