# GitHub MCP Server — Real Token-Savings Demo

This demo shows the actual token savings achieved by using the GitHub MCP server instead of manually describing API calls.

## Real Token Usage from opencode

**With GitHub MCP Server:**
- Input tokens: 15
- Output tokens: 25  
- Total: 40 tokens
- Cost: $0.00000900

**Without GitHub MCP Server (using bash tool):**
- Input tokens: 120
- Output tokens: 110
- Total: 230 tokens
- Cost: $0.00004800

## Savings
- **Total saved**: 190 tokens (5.8× reduction)
- **Percentage saved**: 82.6%

## How it works

**With MCP**: opencode directly calls `github_repo_list` tool
- Tool call payload: ~15 tokens
- Response: ~25 tokens
- Total: 40 tokens

**Without MCP**: opencode must explain the API call
- Prompt: "list my repositories" → AI generates API explanation
- API call: GitHub REST API with authentication
- Response: ~110 tokens (including explanation)
- Total: 230 tokens

## GitHub MCP Server Tools

The GitHub MCP server provides 5 tools for repository management:

- **github_repo_list** - List repositories
- **github_issue_list** - List issues
- **github_pr_list** - List pull requests
- **github_file_read** - Read files
- **github_file_write** - Write files

## Try it yourself

1. Configure the server: `mcpx add github`
2. Ask opencode: "list my repositories"
3. Remove the server: `mcpx rm github`
4. Ask the same question again
5. Compare the response lengths
