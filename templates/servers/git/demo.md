# Git MCP Server — Real Token-Savings Demo

This demo shows the actual token savings achieved by using the Git MCP server instead of manually describing shell commands.

## Real Token Usage from opencode

**With Git MCP Server:**
- Input tokens: 10
- Output tokens: 29  
- Total: 39 tokens
- Cost: $0.00000882

**Without Git MCP Server (using bash tool):**
- Input tokens: 139
- Output tokens: 131
- Total: 270 tokens
- Cost: $0.00004641

## Savings
- **Total saved**: 231 tokens (6.0× reduction)
- **Percentage saved**: 85.6%

## How it works

**With MCP**: opencode directly calls `git_git_status` tool
- Tool call payload: ~10 tokens
- Response: ~29 tokens
- Total: 39 tokens

**Without MCP**: opencode must explain the shell command
- Prompt: "show git status" → AI generates shell command explanation
- Shell command: `git status` 
- Response: ~131 tokens (including explanation)
- Total: 270 tokens

## Git MCP Server Tools

The Git MCP server provides 12 tools for repository management:

- **git_status** - Check repository status
- **git_log** - Show commit history  
- **git_commit** - Create commits
- **git_diff** - Show differences
- **git_add** - Stage files
- **git_reset** - Unstage files
- **git_branch** - List branches
- **git_checkout** - Switch branches
- **git_create_branch** - Create new branches
- **git_show** - Show commit details
- **git_diff_unstaged** - Show unstaged changes
- **git_diff_staged** - Show staged changes

## Try it yourself

1. Configure the server: `mcpx add git`
2. Ask opencode: "show git log with --oneline --graph for the last 5 commits"
3. Remove the server: `mcpx rm git`
4. Ask the same question again
5. Compare the response lengths
