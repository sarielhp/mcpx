# MCP Server Templates

This directory contains templates for MCP (Model Context Protocol) servers.

Each subdirectory represents a different MCP server with:
- `template.json` - Server configuration and metadata
- `demo.md` - Token savings demonstration (generated by `tools/mcpbench`)

## Available Servers

- `git/` - Git operations and repository management
- `github/` - GitHub API operations
- `docker/` - Docker container and image management

## Demo Files

Each server includes a `demo.md` file that shows:
1. How much token usage is reduced with MCP
2. Example prompts and expected token counts
3. The list of tools provided by the server
4. Instructions for users to test it themselves

These demos are generated automatically using the `tools/mcpbench` script.
